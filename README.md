# La Terra nello spazio

Sito statico con il materiale di studio dell'unità T1 (paragrafi 5–11):

- `index.html` – pagina iniziale
- `riassunto.html` – riassunto per studiare, con 11 schemi
- `laboratorio.html` – sei esperimenti interattivi

Il sito è pubblico e non richiede registrazione. Viene pubblicato automaticamente
su GitHub Pages (workflow `.github/workflows/pages.yml`) a ogni push su `main`.
Indirizzo: https://mattiasettembre-cpu.github.io/mio-sito-web/

Per vederlo in locale basta aprire `index.html` nel browser.
